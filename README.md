# Git & GitHub Practical Project

## 📌 Project Overview

This repository was created as part of a Git and GitHub practical exercise. It demonstrates the basic Git workflow, including repository creation, cloning, committing, pushing, branching, and merging.

## 🎯 Objectives

The objectives of this practical are:

* Install and configure Git
* Create and manage a GitHub repository
* Clone a repository locally
* Track files using Git
* Commit and push changes
* Create and work with branches
* Merge branches
* Understand Git workflow and GitHub collaboration

## 🛠️ Technologies Used

* Git
* GitHub
* HTML
* Python

## 🚀 How to Clone

```bash
git clone https://github.com/jayeshzimbal/git-github-practical.git
```

Then enter the project directory:

```bash
cd git-github-practical
```

## 🔄 Git Workflow

The basic workflow used in this project is:

```text
Working Directory
       ↓
    git add
       ↓
  Staging Area
       ↓
   git commit
       ↓
 Local Repository
       ↓
    git push
       ↓
     GitHub
```

## 🌿 Branching

A feature branch was created to make changes without directly modifying the main branch.

```bash
git switch -c feature
```

After completing the changes, the feature branch was merged into the main branch.
